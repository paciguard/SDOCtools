NotoSansSC-Regular.ttf is a static weight-400 instance of the Google Fonts Noto
Sans SC variable font. Source: https://github.com/google/fonts/tree/main/ofl/notosanssc
Original file: NotoSansSC[wght].ttf, retrieved 2026-10-23.
Conversion: fontTools.varLib.instancer source.ttf wght=400 --output NotoSansSC-Regular.ttf
The font remains under SIL Open Font License 1.1; see OFL.txt for copyright/license.
It provides offline Chinese text in mobile vector PDFs without Windows fonts.
