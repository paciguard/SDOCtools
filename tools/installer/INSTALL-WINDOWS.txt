凯乐提交工具 — Windows 独立版

支持 Windows 10（1809 或更新版本）和 Windows 11 的 x64 环境。
安装包包含 .NET 运行库、内置数据库及 DWG 模板和本地图形组件；无需安装 AutoCAD。
在 Excel 中编辑项目参数需要安装桌面版 Microsoft Excel。

安装后，从桌面或开始菜单打开“凯乐提交工具”。
选择“新建项目”并将项目保存在自己的文档文件夹，或选择“打开项目”继续已有项目。
外部项目工作簿使用 .xlsx 格式，仅包含 input，数据表和计算表保存在应用内部。
旧版 .xls 项目将导入为独立的 .xlsx 副本，原文件保持不变。
先选择设备，再通过“剖面材料”“管仪参数”“公用工程参数”修改内部参数。
剖面参数中的轴承架材质会应用到 SEC 图纸及材料明细。
程序不会自动新建项目，也不会自动打开 Excel。
计算成功后，选择“生成 DWG ＋ PDF”。
使用“退出程序”关闭应用；仅关闭浏览器页面不会停止应用。

升级前，请在 Excel 中保存数据并返回工作台，然后退出应用。
卸载可通过 Windows“已安装的应用”完成。卸载不会主动删除您的项目文件。
